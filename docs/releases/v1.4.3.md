# 同频 AudioLink 1.4.3

Windows 多音频设备共享：捕获一个系统播放设备，同时发送到多个耳机、音箱、USB / HDMI 设备或已配对的安卓手机，支持独立音量、静音和同步微调。

## 下载

- **AudioLink-Windows-x64-1.4.3.zip**：Windows x64 便携版，包含 .NET 桌面运行环境。完整解压后运行 `AudioLink.exe`，保留同目录依赖。
- **AudioLink-Android-1.4.0.apk**：Android 8.0 及以上接收端，与 Windows 1.4.3 配套。APK 同时包含在 Windows 包的 `Android` 目录。
- **SHA256SUMS.txt**：下载文件的 SHA-256 校验值。
- **release-manifest.json**：Windows / Android 版本号和源码提交标识。

GitHub 自动提供的 Source code 下载为源码，不是可直接运行的 Windows 程序。

## 更新

- 移除共享设备的「全选 / 取消全选」，通过设备独立开关选择输出，仍可同时启用多个设备。
- 历史设备使用「清除历史 → 勾选 → 确认删除」，支持取消，包含未启用播放的断线记录。
- 精简界面文字，保留设备名称、控件标题、数值和必要状态。
- 保留原音源同步微调、低延迟模式和安卓 USB 网络共享播放。

## 使用

选择正在播放声音的「系统音源」，逐一开启输出设备，再点击「开始共享」。各设备可单独调整音量、静音和 0–500 ms 同步微调。

手机安装配套 APK，开启「USB 网络共享」；电脑点击「连接手机」，在接收端填写电脑地址和连接码。

## 兼容性与验证范围

Windows 包面向 Windows 10 / 11 x64；安卓接收端最低 Android 8.0。1.4.3 的 Release 构建已完成，当前交互验收结果尚未记录；既往音频与协议验证范围见仓库 `VERIFICATION.md`。

跨声卡和蓝牙设备无法保证零延迟或采样级同步。安卓 APK 保持 1.4.0，顶部扬声器底噪及 iQOO 9 真机 USB 兼容性仍需实际设备确认。软件不自动安装虚拟声卡；原音源同步模式需要已有的虚拟中转设备。
